## 🚀 Execution Instructions

1. Identify the target component (e.g. `src/components/TacticalHeader.tsx`, `src/components/PublicPortalHome.tsx`, etc.).
2. Read the corresponding reference playbook in `.agent/skills/impeccable/reference/<command>.md`.
3. Read `.agent/skills/impeccable/reference/craft-floor.md` before applying UI edits.
4. Execute bounded, high-impact refinements following the playbook criteria.
