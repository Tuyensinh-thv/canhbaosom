# Security

HTTPS/TLS; secret management; validation; rate limiting; secure headers; encryption where required; backup/recovery; vulnerability scanning; dependency updates; audit logging.

Threats: account compromise, false data injection, sensor spoofing, alert abuse, data exfiltration, API abuse, model poisoning, prompt injection, unauthorized agent tools.

AI Agent không nhận lệnh từ dữ liệu không tin cậy nếu chưa qua validation/policy.
